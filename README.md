# 🐰 ISUZU RUSH — Trusted Buddy Edition (Web Mobile Endless Runner)

เว็บเกมมือถือ 2D Side-scrolling สไตล์เรซซิ่ง สำหรับกิจกรรมโปรโมตแบรนด์ **ISUZU**
โดยมีตัวละครหลักคือ **กระต่ายมาสคอต ISUZU Trusted Buddy (TSH)** ในชุดช่างสีน้ำเงินคาดแดง วิ่งตะลุยสุดทางผ่านการสแกน QR Code หรือคลิกลิงก์ออนไลน์ โดยไม่ต้องติดตั้งแอปพลิเคชัน

---

## 🌟 จุดเด่นและฟีเจอร์ใหม่ (Mascot Edition)

- 🐰 **ตัวละครหลัก: กระต่ายมาสคอต ISUZU Trusted Buddy (TSH)**:
  - สวมชุดช่างสีน้ำเงิน Trusted Buddy Blue (`#4A5BB5`) คาดแถบแดงเรซซิ่ง (`#DD0000`) พร้อมตรา TSH
  - ระบบแอนิเมชันวิ่ง 60 FPS: ตัวเด้งขึ้นลงตามจังหวะก้าว (Bobbing), เอียงตัวไปข้างหน้าเล็กน้อยตอนวิ่ง, สควอช & สเตรชตอนกระโดดและลงพื้น, หูกระดิกตามแรงลม และมีฝุ่นควันที่เท้า
  - **ระบบกระโดด 2 จังหวะ (Double Jump)**: แตะหน้าจอซ้ำกลางอากาศเพื่อลอยตัวข้ามสิ่งกีดขวางขนาดใหญ่
  - **Hitbox เป็นธรรม**: ขนาดกล่องชนประมาณ 65% ของลำตัว ไม่รวมหูยาว เพื่อให้ผู้เล่นไม่รู้สึกถูกจับผิด
  - **บับเบิ้ลคำเชียร์แบบสุ่ม**: กระต่ายจะพูดให้กำลังใจเป็นระยะ เช่น *"ไปต่อเลย!", "เก่งมาก!", "ระวังข้างหน้า!", "สู้ๆ นะเพื่อน!"* (ปรับแต่งได้ง่ายใน `assets.config.js`)
- 🥕 **ไอเท็มเก็บคะแนน**:
  - **แครอท (Carrot)** = +10 คะแนน (แทนเหรียญ)
  - **ตั๋ว VIP สีฟ้า (Ticket)** = +50 คะแนน (ลอยสูงในอากาศ)
  - **กุญแจรถ TSH (TSH Smart Key)** = โบนัสพิเศษ **+100 คะแนน และเปิดใช้งานตัวคูณคะแนน 2 เท่าทันทีเป็นเวลา 5 วินาที!**
  - **ที่ชาร์จ/น้ำมัน (Charger)** = ฟื้น 1 พลังชีวิต
- 🚧 **สิ่งกีดขวาง**:
  - กล่องเครื่องมือช่าง (Toolbox), ยางรถยนต์ (Tire), กรวยจราจร (Cone), หลุมถนน (Pothole), ก้อนหิน (Rock)
  - **รถกระบะอีซูซุวิ่งสวนมา (Isuzu D-Max Truck)**: สิ่งกีดขวางขนาดยักษ์ที่ต้องจับจังหวะกระโดดข้าม
  - ไม่มีภาพความรุนแรง: ตัวละครจะแค่สะดุ้ง ช็อค และกะพริบอมตะชั่วครู่
- ⚡ **มินิบอส Speed Rush ทุกๆ 1,000 เมตร**:
  - เมื่อวิ่งครบ 1,000 ม. จะมีสัญญาณเตือนฝูงสิ่งกีดขวางถี่ขึ้น 10 วินาที หากผ่านได้จะได้โบนัสใหญ่ **+250 คะแนน**
- 🎨 **การจัดการแบรนด์และไฟล์ Config กลาง (`/public/js/assets.config.js`)**:
  - หน้า Splash: โลโก้ ISUZU เต็มสัดส่วนมาตรฐานไม่ถูกยืด พร้อมกระต่ายยกนิ้วโป้ง (Thumbs-up)
  - หน้าสรุปผล: กระต่ายยกนิ้วโป้ง (เมื่อติด Top 10) หรือท่าให้กำลังใจ (เมื่ออยู่นอก Top 10)
  - สามารถสลับหรือเปลี่ยนไฟล์รูปภาพ โลโก้ และข้อความเชียร์ได้ในไฟล์ config เดียว โดยไม่ต้องแตะต้องโค้ดระบบเกม

## 🚀 วิธีการทดสอบและรันโปรเจกต์

เซิร์ฟเวอร์กำลังรันอยู่ในพื้นหลังที่พอร์ต **3000**:

1. **หน้าเกม ISUZU Trusted Buddy**: [http://localhost:3000/](http://localhost:3000/)
2. **หน้าดาวน์โหลด QR Code สำหรับพิมพ์สื่อโปรโมต**: [http://localhost:3000/qr](http://localhost:3000/qr)
3. **แผงควบคุมแอดมิน (Admin Dashboard)**: [http://localhost:3000/admin](http://localhost:3000/admin) *(รหัส PIN: `isuzu2026`)*
